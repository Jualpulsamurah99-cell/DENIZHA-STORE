# DENIZHA CELL

Website toko digital untuk:
- Pulsa
- Kuota internet
- Dompet digital
- Token listrik

## Cara mengubah WhatsApp
Buka `app.js`, cari:
`whatsapp: "6281234567890"`
Ganti dengan nomor WhatsApp kamu, contoh `628xxxxxxxxxx`.

Lalu buka `payment.html` dan ganti nomor yang sama pada bagian CONFIG.

## Cara memasang QRIS
Simpan gambar QRIS milik kamu dengan nama:
`qris.png`
di folder yang sama dengan `index.html`.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file dalam folder ini.
3. Masuk Settings → Pages.
4. Source: Deploy from a branch.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save.
7. GitHub akan memberikan alamat website.

Catatan: versi ini adalah website statis. Pembayaran QRIS ditampilkan sebagai QRIS milik toko dan konfirmasi dilakukan lewat WhatsApp. Status pembayaran belum diverifikasi otomatis oleh sistem pembayaran.
